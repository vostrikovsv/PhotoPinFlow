# PhotoPinFlow Privacy Policy

Effective date: July 8, 2026

This Privacy Policy describes how PhotoPinFlow handles information when used to publish content through the Pinterest API.

## 1. Information We Collect

PhotoPinFlow is a local publishing tool. It may process images selected by the user for publishing.

PhotoPinFlow may also process post metadata entered or generated by the user, including titles, descriptions, hashtags, alt text, and board selections.

PhotoPinFlow may store authorization tokens required to publish content and read boards through the Pinterest API.

PhotoPinFlow may keep local activity logs, such as publishing status, API request status, and error messages.

## 2. How We Use Information

We use this information only to authenticate the user, read the user's boards, create and publish content selected by the user, show publishing status and errors, prevent duplicate uploads, and manage the local publishing queue.

## 3. Local Storage

PhotoPinFlow stores configuration, publishing queue data, and authorization tokens locally on the user's own computer.

This data is not uploaded to our servers.

## 4. Third-Party Services

PhotoPinFlow uses the Pinterest API to authenticate the user, read boards, and create standard Pins.

If AI image analysis is enabled by the user, selected images and related metadata may be sent to the configured AI provider only for generating titles, descriptions, hashtags, and alt text.

## 5. Data Sharing

We do not sell, rent, or share personal information with advertisers or data brokers.

Information is shared with Pinterest only when the user authorizes PhotoPinFlow and chooses to publish content through the Pinterest API.

## 6. Data Retention

PhotoPinFlow keeps local publishing history and configuration files on the user's computer until the user deletes them.

The user may delete local data at any time by removing the app folder, database file, configuration file, or stored tokens.

## 7. User Control

The user controls which images are added to the publishing queue and which content is published.

The user can revoke API access at any time through their account settings.

## 8. Security

We take reasonable measures to protect locally stored data. However, the user is responsible for keeping their computer, files, and API credentials secure.

## 9. Children's Privacy

PhotoPinFlow is not intended for use by children under 13, and we do not knowingly collect information from children.

## 10. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated effective date.
