# PhotoPinFlow

PhotoPinFlow is a local publishing tool for creators and photographers.

It helps users prepare, organize, and publish their own images as standard Pins through the Pinterest API.

PhotoPinFlow reads the user's boards, creates posts selected by the user, stores a local publishing queue, and shows publishing status and API errors.
